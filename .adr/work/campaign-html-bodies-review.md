## Verified (no finding)

- `Schema.optionalKey`: decoding `{ html: undefined }` fails (`Expected string at ["html"]`), `{ html: "" }` fails on `isNonEmpty`, absent key decodes to an object without the key; **encoding** `{ html: undefined }` also fails, which is why every projection (`getCampaign`, `Campaigns.create`, the CLI in-memory `create`) must spread conditionally. `exactOptionalPropertyTypes: true` turns `html: payload.html` into TS2375, so the compiler enforces it. (Executed against installed Effect; `tsc` with the repo's options.)
- `Schema.String.check(Schema.isNonEmpty(), Schema.makeFilter(...))` type-checks: `check` takes `SchemaAST.Check<string>`, `isNonEmpty()` is a `Filter` over `{ length: number }` (contravariant), `makeFilter<string>` yields `Filter<string>`. Byte limit measured in UTF-8 (`"éé"` at a 4-byte ceiling passes, `"ééé"` fails). `Schema.ts:191, 5135-5139, 6659`.
- `Flag.fileText("html").pipe(Flag.withDescription, Flag.withSchema(CampaignHtml), Flag.optional)` type-checks to `Flag<Option<string>>`; `Param.optional` catches `MissingOption` generically, so the order matches the existing `limitFlag`. `Primitive.fileText` fails with `File does not exist: <abs path>` before any request → parser error → nonzero exit. `Flag.ts:335, 775, 2026`; `Param.ts:1615-1636`; `Primitive.ts` (`fileText`). The CLI provides `FileSystem` through `NodeServices.layer` (`apps/cli/src/main.ts`); the harness already imports `writeFile`, `rm`, `tmpdir` and spawns with the repo as cwd (`Commands.test.ts:11-15, runCli`).
- sesv2 types: `Body { Text?; Html? }`, `Message.Headers?` unchanged; two parts type-check under `AWS.SES.SendEmailRequest`. The distilled client encodes the request through `Schema.encodeEffect(SendEmailRequest)` where `Body.Html` is `S.optional(Content)`, so even `Html: undefined` is tolerated and dropped by `JSON.stringify` — the text-only wire body is identical either way. The T3 assertion compares parsed JSON with `toStrictEqual`, so "byte-identical" means "structurally identical"; fine. `sesv2.d.ts:431-476`; `sesv2.js` (`Body`); `protocols/rest-json.js:31, 111, 162-170`.
- `IntegrationSupport`: `sendToSimulatorList` (238-251), `awaitCampaignState` (330-362), `sendRows` (405-435) and `campaignStateTimeout` (321-328) support T6 as written; only the assertion strength is at issue (finding 2).
- `withOptional` writes an attribute only when defined (`Items.ts:92-107`); `html` is not a DynamoDB reserved word; the reserved-word assertion at `Campaigns.test.ts:45` is unaffected.
- Every `CampaignStore` fake that constructs a `CampaignRun` is `Dispatching.test.ts:159-175` only (`Api.test.ts:46` and `Campaigns.test.ts:140` are `notExercised`), so T4's fixture change is the whole set.

## Verdict

**Revise.** Findings **1** and **2** must be addressed before implementation: without a `Campaigns.create` change the feature silently does not persist, and the live gate as written would report green anyway. Findings 3–5 and 9 are small wording or scope corrections worth folding in at the same time; the rest are nits with no required action.
